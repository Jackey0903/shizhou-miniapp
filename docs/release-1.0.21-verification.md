## 正式发布

审核通过后在微信公众平台进入“管理 -> 版本管理”，确认审核版本为 `1.0.21`，点击“发布”。

发布完成后使用普通用户和管理员账号分别执行以下冒烟测试：

1. 普通用户登录、答题、领取一份资料并再次打开。
2. 打卡生成海报并保存或分享，检查舟币变动。
3. 分别打开 VIP 和督学购买页，确认套餐分离及支付入口正常。
4. 管理员进入工作台，检查题库、资料、音频、壁纸和运营配置列表。
5. 管理员生成正式小程序码并保存。

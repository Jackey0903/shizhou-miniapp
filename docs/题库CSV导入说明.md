# 仕舟题库 CSV 导入说明

## 固定文件格式

- 文件类型：`CSV UTF-8（逗号分隔）`
- 固定表头：`科目名称,题库名称,序号,题型,题目,选项A,选项B,选项C,选项D,答案,解析,图片URL`
- 不得删除、改名或调换表头。
- 用 Excel/WPS 编辑后，选择“另存为 -> CSV UTF-8（逗号分隔）”。

## 填写规则

1. `科目名称`、`题库名称`、`题型`、`题目`、`答案` 每行必填。
2. `题型` 只能填 `选择题` 或 `填空题`。
3. 选择题至少填选项 A、B，选项不能跳列；答案只填 `A/B/C/D`。
4. 填空题的选项列留空，`答案` 填完整参考答案。
5. `序号` 可留空，系统按文件顺序自动生成。
6. `解析`、`图片URL` 可留空；图片只支持 `https://` 或 `cloud://` 地址。
7. 文件先发到微信文件传输助手或管理员聊天，再在小程序“我的 -> 题目录入”中选择。

## 导入流程

1. 管理员点“发送 CSV 模板”，将模板发给自己或客户。
2. 客户在 Excel/WPS 按模板填题，另存为 CSV UTF-8 后发回管理员。
3. 管理员选择 CSV，查看校验结果和前 5 题预览。
4. 无错误时点“确认导入”。重复题目会自动跳过，可安全重试。

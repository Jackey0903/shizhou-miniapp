## 本轮发现并修复

### 后台音频页面卸载后偶发异常

现象：磨耳朵使用 `BackgroundAudioManager` 播放后离开页面，微信偶尔继续发送排队中的进度回调；页面已释放音频对象时会报错：

```text
Cannot read property 'currentTime' of null
```

修复：所有后台音频回调在页面释放音频对象后立即返回，不再读写已卸载页面。

验证：真实播放正式环境音频后离开页面，无异常；`scripts/regression-audio-lifecycle.js` 已加入发布回归。

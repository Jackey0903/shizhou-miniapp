# 1.0.32 题目管理发布说明

## 本次新增

- 管理员工作台新增“题目管理”入口。
- 普通管理员与最高管理员均可按题库查看题目，并搜索题干、选项、答案和解析。
- 可编辑题型、序号、题干、题图地址、选项、正确答案、参考答案和解析。
- 可将题目下线或重新上线；下线后题目不会返回给普通用户。
- 可二次确认后永久删除题目。删除不会删除既有答题记录，题库的可用题目数会同步更新。
- 所有编辑、上下线和删除动作均写入管理员审计日志。

## 权限

- 普通用户：无权访问题目管理接口或页面。
- 普通管理员：可查看、搜索、编辑、上下线和永久删除题目。
- 最高管理员：拥有与普通管理员相同的题目管理权限，并保留原有的管理员账号管理权限。

## 验收范围

发布前已运行以下自动回归：

1. 普通用户访问题目管理接口被拒绝。
2. 管理员按题库检索、关键词搜索、编辑、下线、上线和删除均可执行。
3. 选择题必须存在有效的正确答案，编辑不会制造重复题。
4. 下线题目不返回给用户端；分页不会因首条下线题目而漏题。
5. 永久删除后题库可用题数更新，历史答题记录保留。
6. 页面保存成功后关闭编辑窗口，并刷新题目列表。

## 发布顺序

1. 先部署 `adminOperations` 与 `getQuestions` 云函数。
2. 上传小程序开发版 `1.0.32`。
3. 使用普通管理员账号和最高管理员账号分别验证入口、搜索、编辑与下线。
4. 使用普通用户账号确认看不到管理员入口，且下线题目不在题库中出现。
5. 通过审核后发布正式版。

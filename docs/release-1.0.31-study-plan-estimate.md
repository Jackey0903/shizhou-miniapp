# 1.0.31 学习计划预计完成日期修复与验收记录

## 问题

客户录像中“申论母题”显示每日 4 题、已学 2/57 题，但剩余时间为 0 天，完成日期仍为已经过期的 2026-08-05。原实现把完成日期作为手动保存的固定日期，修改每日题数、完成题目或日期过期后都不会更新。

## 修复

1. “完成日期”改为只读的“预计完成日期”，不再让用户手动选择。
2. 预计学习天数按 `向上取整((总题数 - 已学题数) / 每日题数)` 计算。
3. 当天计为第一个学习日，预计完成日期为当天加“预计学习天数 - 1”。
4. 调整每日题数、重新打开页面、完成新题或跨自然日后均实时重算。
5. 学习计划、我的新学本和日历统一使用同一计算函数，历史过期日期不再影响显示。
6. 保存计划时把当前预计日期同步写入云端，兼容既有数据结构。

## 客户场景

- 总题数：57
- 已学题数：2
- 剩余题数：55
- 每日题数：4
- 预计还需：14 个学习日
- 若从 2026-08-16 当天开始，预计完成日期：2026-08-29

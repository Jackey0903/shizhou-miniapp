# 1.0.30 登录审核合规修复记录

## 审核反馈

微信审核指出手机号快速验证组件的前置页面存在易与腾讯官方混淆的登录表述，要求去除“微信”字样、微信官方 Logo 等元素，并建议将手机号授权入口修改为“手机号快捷登录”。

## 修改内容

- 登录按钮由“微信登录并绑定手机号”改为“手机号快捷登录”。
- 登录页不再出现“微信”字样或腾讯、微信官方 Logo。
- 页面保留仕舟自有角色 Logo、仕舟公考名称和自有品牌文案。
- 用户协议改为“通过手机号快速验证组件授权并绑定手机号”。
- 隐私政策同步使用“手机号快捷登录”和“平台提供的安全接口”表述。
- 手机号唯一绑定、`open-type="getPhoneNumber"`、用户勾选协议后才能授权等业务和隐私逻辑保持不变。
- 发布检查新增登录页混淆表述门禁，禁止再次引入“微信登录”“微信官方能力”“微信授权”等文案。

## 验收结果

- 代码扫描：登录页、用户协议和隐私政策中不存在被审核指出的混淆登录表述。
- 自动化渲染：按钮文字为“手机号快捷登录”。
- 自有 Logo：83x83 显示区域正常。
- 开发者工具：页面路径 `pages/login/login`，控制台 0 错误。
- 完整发布回归：27 组通过，检查 144 个 JavaScript 文件。

## 复审说明建议

已按修改指引去除登录前置页面中易与腾讯官方混淆的“微信登录”表述，手机号授权按钮已改为“手机号快捷登录”，页面仅保留仕舟自有角色 Logo；用户协议及隐私政策中的相关旧表述也已同步修正。手机号快速验证组件和隐私授权流程保持合规使用。

# 1.0.41 备考匹配广场与反馈文案

## 改动

- “督学匹配”公开展示已发布的备考帖子；普通用户和管理员均可浏览，全职与在职帖子均可见。
- “保存草稿”与“发布备考帖子”分开。发帖、浏览和互选匹配不依赖付费督学。
- 双方互相表示匹配意向后才显示联系方式；取消意向会立即隐藏联系方式；退出广场会下线帖子并清除匹配意向。
- “开通督学服务”仍独立进入原有付费套餐。
- “推荐有礼”改为“反馈有礼”，去除引导用户到外部平台发布内容和必得奖励的文字，使用客户指定的六段文案。

## 验证

- 多账号云函数回归：未付费发帖、跨分类浏览、管理员浏览、未发布账号不能发起匹配、双方互选、取消意向、退出、分页。
- 页面回归：帖子渲染、分页按钮、匹配按钮、发布后不强制跳转付费、付费独立入口。
- 反馈页面六段文案逐字检查，无旧平台发布要求。
- 正式云环境 `supervisionMatch` 已部署，开发者工具调用公开列表返回 2 条帖子；未互选帖子的联系方式均未返回。
- 开发者工具模拟器可见公开帖子和匹配按钮；“反馈有礼”页的五段正文与指定文案逐字一致。

`1.0.41` 开发版已于 2026-09-26 上传成功，包体 784,896 字节。上传不等于审核或正式发布。本轮未用真实用户账号互相发送匹配意向，互选及撤回流程由多账号云函数回归测试覆盖。

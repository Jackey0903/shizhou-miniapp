# 1.0.39 资料舟币提示修复与验收记录

> 2026-09-16 后续调整：基础 VIP 已在 `1.0.40` 改为 365 天 VIP + 30 天督学。下文保留为 `1.0.39` 上传时的历史验收记录。

## 变更内容

- 资料首次领取固定消耗 10 舟币，已领取资料再次打开不重复扣费。
- 余额不足时，资料页直接显示“去分享”入口，用户可以进入舟币中心完成分享任务。
- 领取资料时使用合法的原生弹窗按钮文字“去分享”，避免微信原生 `showModal` 因按钮文字过长而不显示弹窗。
- 从舟币中心返回资料页后重新加载余额，避免页面继续使用旧余额。
- 舟币中心规则文案与实际规则一致：分享任务每次获得 10 舟币，每类任务每天最多 20 舟币；完整看完广告获得 1 舟币。

## 套餐入口说明

套餐按产品规则分离：

| 页面 | 套餐 |
| --- | --- |
| `我的 -> 加入VIP` | 基础 VIP、 高级 VIP |
| `督学匹配 -> 督学开通` | 督学试用、督学包月、督学包年 |

基础 VIP 当前配置为 365 天 VIP、0 天督学；督学包月当前配置为 30 天督学。高级 VIP 与督学包年共用 988 元正式道具，包含 365 天 VIP 和 365 天督学。

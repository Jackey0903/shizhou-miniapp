# 1.0.29 素材兼容修复与验收记录

## 问题与根因

客户反馈新发布版本首页 Logo 不显示。检查确认 Logo 文件没有被上传规则排除，实际根因是 Logo 和多个默认图片使用了主包 WebP 格式。该格式在开发者工具中可见，但部分微信及鸿蒙真机对主包图片的读取或解码不稳定，因此线上表现为图片空白。

## 修复内容

- 将 Logo、默认头像、默认课程封面、默认打卡背景和四张默认壁纸转换为基线 JPEG。
- 将首页、登录、个人中心、管理员页面、打卡、壁纸、课程和分享配置的引用统一更新为 JPEG。
- 修复旧版 Canvas 将主包绝对路径错误解析为页面相对路径的问题，避免打卡海报和壁纸生成时请求 `/pages/.../assets/...` 并返回 500。
- 删除主包内全部 WebP 和无显示价值的 1x1 透明课程封面。
- 保留客服二维码为 PNG，并在不改变 439x600 像素尺寸的前提下降低包体体积。
- 发布门禁会扫描页面和工具代码中的本地素材路径，引用不存在时直接失败。
- 发布门禁禁止主包包含 WebP，并要求主包全部图片和音频总量小于 200 KiB。
- 开发者工具图片测试覆盖 Logo、头像、课程封面、打卡背景、四张壁纸、客服二维码和正式小程序码。
- 生产云审计会逐条校验壁纸、音频、资料和小程序码的数据库 `fileId` 在云存储中真实存在且文件大小大于 0。

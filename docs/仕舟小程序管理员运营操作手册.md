# 仕舟小程序管理员运营操作手册

适用对象：仕舟小程序运营管理员、内容管理员、微信公众平台管理员  
适用系统：仕舟公考微信小程序  
编写日期：2026-07-25  
云开发正式环境：`cloud-2ge02vrucaf8a6ab`

---

## 1. 使用前必读

### 1.1 三类管理入口

仕舟小程序的管理工作分布在三个入口。操作前先确认自己应该进入哪个入口。

| 管理入口 | 用途 | 本手册涉及内容 |
| --- | --- | --- |
| 仕舟小程序管理员页面 | 日常内容维护 | 题库、音频、资料、壁纸、打卡海报、消息、帮助内容、广告位 ID |
| 微信公众平台 | 微信平台能力管理 | 开通流量主、创建广告位、下载正式小程序码 |
| 微信开发者工具的云开发控制台 | 高风险运维操作 | 下架题库模块、给指定用户免费开通会员或督学权限 |

日常运营优先使用小程序内管理员页面。只有小程序内没有入口时，才进入云开发控制台。

### 1.2 管理员入口

1. 在微信中打开正式版“仕舟”小程序。
2. 完成登录。
3. 点击底部“我的”。
4. 向下滑动，找到管理员菜单。

管理员通常可以看到以下菜单：

- 题目录入
- 题库管理
- 音频上传
- 资料上传
- 壁纸上传
- 提醒配置
- VIP 套餐管理
- 消息推荐管理
- 广告位管理
- 帮助反馈配置
- 打卡背景管理
- 打卡文案管理

如果看不到这些菜单，说明当前微信账号没有管理员权限。技术管理员需要在正式环境 `users` 集合中为该账号设置：

```json
{
  "isAdmin": true
}
```

也可以设置：

```json
{
  "role": "admin"
}
```

### 1.3 通用安全规则

1. 不要在生产环境运行“初始化数据”“种子数据”“清空数据”等功能。
2. 不要直接删除题库、题目、用户和订单数据。
3. 需要下架内容时，优先使用“停用”或将 `status` 改为 `disabled`。
4. 修改云数据库前，先截图或导出原记录。
5. 修改完成后必须使用普通用户账号进行验收，不能只看管理员页面。
6. 正式 AppSecret、AppKey、支付密钥和访问令牌不得发到群聊、文档或截图中。

## 2. 批量上传和内容设置

### 2.1 功能支持范围

| 内容类型 | 小程序入口 | 当前单次处理数量 | 说明 |
| --- | --- | ---: | --- |
| 题库题目 | 我的 -> 题目录入 | 最多 5000 题/CSV | 真正的批量导入 |
| 磨耳朵音频 | 我的 -> 音频上传 | 最多 9 个文件 | 同一批统一设置模块、标签和时长说明 |
| 壁纸 | 我的 -> 壁纸上传 | 1 张 | 需要逐张上传 |
| 领取资料文档 | 我的 -> 资料上传 | 1 份 | 需要逐份上传 |
| 领取资料音频 | 我的 -> 资料上传 | 1 份 | 需要逐份上传 |
| 领取资料图片 | 我的 -> 资料上传 | 1 张 | 需要逐张上传 |

注意：资料上传和壁纸上传当前不是多选批量上传。不要一次选择压缩包，也不要把多个文件合并成一个文件后冒充多份资料。

### 2.2 批量导入题库

#### 2.2.1 准备固定模板

1. 进入“我的 -> 题目录入”。
2. 点击“发送 CSV 模板”。
3. 将模板发送到文件传输助手，或发送给负责整理题库的人员。
4. 使用 Excel 或 WPS 打开模板。
5. 完成填写后，选择“另存为 -> CSV UTF-8（逗号分隔）”。

只接收 `.csv` 文件，不接收 `.xlsx`、`.xls`、Word 或 PDF。

固定表头如下，不得删除、改名或调换：

```text
科目名称,题库名称,序号,题型,题目,选项A,选项B,选项C,选项D,答案,解析,图片URL
```

#### 2.2.2 字段填写规则

| 字段 | 是否必填 | 填写规则 |
| --- | --- | --- |
| 科目名称 | 是 | 建议统一使用：常识、言语理解、逻辑判断、数量关系、资料分析、申论、综应、面试 |
| 题库名称 | 是 | 同一批题必须填写准确的题库名称 |
| 序号 | 否 | 正整数；留空时系统按导入顺序处理 |
| 题型 | 是 | 只能填写“选择题”或“填空题” |
| 题目 | 是 | 每题一行，最长 5000 个字符 |
| 选项 A-D | 选择题必填 | 至少填写 A、B；不能跳列，例如不能只填 A、C |
| 答案 | 是 | 选择题只填 A/B/C/D；填空题填写完整参考答案 |
| 解析 | 否 | 建议填写，方便用户学习 |
| 图片 URL | 否 | 只支持 `https://` 或 `cloud://` 地址 |

图片题注意事项：

- CSV 不能直接嵌入本地图片。
- 本地图片必须先由技术人员上传到云存储或稳定的 HTTPS 地址。
- 不要使用有登录限制、会过期或防盗链的临时图片地址。
- 图片在答题页按原比例宽度自适应显示，建议宽度至少 1080 像素，文字清晰可读。

#### 2.2.3 选择题示例

```text
常识,法律常识,1,选择题,下列哪一项符合题意？,选项一,选项二,选项三,选项四,A,这里填写解析,
```

#### 2.2.4 填空题示例

```text
申论,归纳概括,1,填空题,请概括材料反映的主要问题。,,,,,这里填写参考答案,这里填写评分要点,
```

#### 2.2.5 导入流程

1. 将 CSV 文件发送到当前管理员微信的文件传输助手或聊天窗口。
2. 进入“我的 -> 题目录入”。
3. 点击“选择 CSV 文件”。
4. 选择刚才发送的 CSV。
5. 查看校验结果、错误行号和前 5 题预览。
6. 有错误时先修改原 CSV，再重新选择文件。
7. 校验通过后点击“确认导入”。
8. 等待系统提示导入完成，中途不要退出小程序。

系统限制：

- 单个 CSV 最大 5MB。
- 单个 CSV 最多 5000 题。
- 系统自动分批上传，不需要人工拆成多个按钮操作。
- 重复题会自动跳过，可以在网络中断后重新导入同一个文件。

#### 2.2.6 VIP 题库的正确做法

如果某个题库只允许 VIP 用户使用：

1. 先进入“我的 -> 题库管理”。
2. 创建对应科目和题库。
3. 勾选“VIP 题库”。
4. 再导入 CSV，并确保 CSV 中的“科目名称”和“题库名称”与刚创建的内容完全一致。

如果直接导入一个不存在的题库，系统会自动创建，但默认不会自动设为 VIP 题库。

#### 2.2.7 导入后验收

每次导入完成后必须检查：

- [ ] 首页或“查看更多”中出现正确科目
- [ ] 题库名称、标签和说明正确
- [ ] 题目总数与 CSV 数量基本一致
- [ ] 随机打开至少 2 道选择题
- [ ] 随机打开至少 2 道填空题
- [ ] 答案、解析和图片正常
- [ ] VIP 题库使用普通账号会提示开通 VIP

### 2.3 批量上传磨耳朵音频

#### 2.3.1 支持格式

- `.mp3`
- `.wav`
- `.m4a`

推荐使用 MP3，码率 64-128kbps。系统没有写死单文件大小上限，但文件过大会受到微信文件选择、网络和云存储上传限制。运营上建议每个文件不超过 20MB。

#### 2.3.2 文件命名建议

上传前先把文件名改成用户能看懂的标题，例如：

```text
法律常识_行政法基础.mp3
言语_成语辨析01.mp3
资料_增长率速算技巧.mp3
```

系统会自动去掉扩展名，并把文件名作为音频标题。

#### 2.3.3 上传流程

1. 先把音频文件发送到管理员微信的文件传输助手。
2. 进入“我的 -> 音频上传”。
3. 选择所属模块：常识、数量、言语、逻辑、资料、申论、综应或面试。
4. 选择音频标签：晨听、单词、技巧或素材。
5. 填写时长说明，例如 `05:20`。此字段可留空。
6. 点击“选择音频文件”，一次最多选 9 个。
7. 检查文件列表。
8. 点击“开始批量上传”。
9. 等待“已上传 X 个音频”的提示。

同一批文件会共用同一个“所属模块”“音频标签”和“时长说明”。如果多个音频时长不同，建议按文件分别上传，或统一不填写时长。

#### 2.3.4 上传后验收

1. 返回首页。
2. 进入“磨耳朵”。
3. 切换到刚才选择的模块。
4. 检查标题、标签和时长。
5. 播放第一个和最后一个文件。
6. 测试暂停、进度条、连续播放和切后台播放。

当前管理员页面没有音频编辑和删除按钮。需要下架时，由技术管理员在正式环境 `audios` 集合中把对应记录的 `enabled` 改为 `false`，不要直接删除云存储文件。

### 2.4 上传壁纸

#### 2.4.1 推荐图片规格

| 项目 | 推荐值 |
| --- | --- |
| 方向 | 竖图 |
| 比例 | 9:16 |
| 推荐尺寸 | 1080 x 1920 像素 |
| 最低建议尺寸 | 900 x 1600 像素 |
| 格式 | JPG 或 PNG |
| 色彩 | sRGB |
| 文件大小 | 建议不超过 5MB |

壁纸列表卡片使用约 9:15.5 的竖向区域，并采用居中裁切。因此：

- 主要人物、标题和二维码不要贴近四周。
- 建议左右至少保留 60 像素安全边距。
- 建议顶部和底部至少保留 100 像素安全边距。
- 重要文字不要放在最底部，避免被操作按钮遮挡。

壁纸分享时会生成正方形分享图。系统会用柔化背景填充空白，并完整放入原壁纸，所以竖图主体不会被强制截断。

#### 2.4.2 上传流程

1. 进入“我的 -> 壁纸上传”。
2. 填写壁纸标题。留空时默认显示“平台壁纸”。
3. 点击“选择壁纸图片”。
4. 从手机相册选择 1 张图片。
5. 查看预览。
6. 点击“上传壁纸”。
7. 等待“壁纸已上传”的提示。

当前每次只能上传 1 张壁纸，需要逐张操作。

#### 2.4.3 上传后验收

1. 返回首页，进入“屏保壁纸”。
2. 确认新壁纸已出现。
3. 点击图片查看大图。
4. 测试“保存”“编辑”“分享朋友圈”和“用于打卡”。
5. 确认人物和文字没有被列表卡片裁掉。

当前管理员页面没有壁纸编辑和删除按钮。需要下架时，由技术管理员在正式环境 `wallpapers` 集合中把对应记录的 `enabled` 改为 `false`。

### 2.5 上传领取资料

#### 2.5.1 当前领取规则

- 文档、音频和图片都属于“领取资料”。
- 用户第一次领取每一份资料固定消耗 10 舟币。
- 同一用户再次打开已经领取的资料，不会重复扣费。
- 当前不能在管理员页面为不同资料设置不同舟币价格。

#### 2.5.2 支持格式

文档支持 PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX 和 TXT。  
音频支持 MP3、WAV 和 M4A。  
图片从手机相册选择常见图片格式。

#### 2.5.3 资料封面尺寸

资料列表中的封面是正方形，并使用居中裁切。

| 项目 | 推荐值 |
| --- | --- |
| 比例 | 1:1 |
| 推荐尺寸 | 800 x 800 像素 |
| 最低建议尺寸 | 400 x 400 像素 |
| 格式 | JPG 或 PNG |
| 文件大小 | 建议不超过 2MB |

封面制作要求：

- 标题和图标放在中央区域。
- 四周至少保留 60 像素安全边距。
- 不要使用过小文字。
- 不上传封面时，列表会显示系统默认文件图标。

图片资料本身不要求正方形。普通图片建议宽度 1080 像素；长图保持原比例，确保微信大图预览时文字清晰。

#### 2.5.4 上传流程

1. 进入“我的 -> 资料上传”。
2. 选择资料类型：文档、音频或图片。
3. 填写资料标题。留空时系统使用文件名。
4. 填写资料说明。
5. 选择以下一种来源：
   - 点击“选择资料文件”上传本地文件。
   - 填写稳定的 HTTPS 或 `cloud://` 资料链接。
6. 点击“选择资料封面”，上传正方形封面。封面可选。
7. 点击“上传资料”。
8. 等待“资料已上传”的提示。

使用外部链接时：

- 必须使用 HTTPS，不能使用 HTTP。
- 链接不能要求浏览器登录。
- 链接不能是短期临时地址。
- 文档链接最好以实际文件扩展名结尾。

#### 2.5.5 上传后验收

使用普通测试账号验收：

1. 确保账号至少有 10 舟币。
2. 进入“领取学习资料”。
3. 切换到对应的“文档”“音频”或“图片”页签。
4. 检查标题、说明和封面。
5. 第一次点击“领取”，确认出现消耗 10 舟币提示。
6. 领取成功后检查余额减少 10。
7. 再次打开同一资料，确认不再扣费。
8. 文档应能打开，音频应能播放，图片应能大图预览。

当前资料上传页每次只能上传 1 份资料，也没有编辑和删除按钮。需要下架时，由技术管理员在正式环境 `materials` 集合中把对应记录的 `enabled` 改为 `false`。

## 3. 记忆卡模块增减

### 3.1 标准模块名称

建议统一使用以下 8 个名称，不要混用简称：

1. 常识
2. 言语理解
3. 逻辑判断
4. 数量关系
5. 资料分析
6. 申论
7. 综应
8. 面试

例如，“言语”和“言语理解”会被系统当成两个不同模块；“数量”和“数量关系”也会被当成两个不同模块。

### 3.2 新增模块

模块必须至少有一个题库才会显示。

1. 进入“我的 -> 题库管理”。
2. 在“科目名称”中填写标准模块名称。
3. 填写题库名称，例如“基础知识 1000 题”。
4. 填写题库标签，例如“基础题库”或“高频真题”。
5. 填写题库说明。
6. 如果只允许 VIP 使用，勾选“VIP 题库”。
7. 点击“创建题库”。
8. 再进入“题目录入”导入该题库的题目。

首页只展示排序最靠前的 8 个模块。超过 8 个后，新模块仍会显示在“考点记忆卡 -> 查看更多”中。

### 3.3 给现有模块增加题库

1. 进入“我的 -> 题库管理”。
2. 科目名称填写已有模块的准确名称。
3. 填写一个新的题库名称。
4. 保存后再导入题目。

同一科目下不允许创建同名题库。

### 3.4 减少或下架模块

当前小程序管理员页面只支持新增，不支持改名、排序或删除。下架操作必须由技术管理员进行。

安全下架流程：

1. 打开微信开发者工具。
2. 进入“云开发”。
3. 确认环境为 `cloud-2ge02vrucaf8a6ab`。
4. 进入“数据库 -> question_banks”。
5. 按 `category` 或 `subjectName` 找到目标模块下的所有题库。
6. 逐条把 `status` 改为字符串 `disabled`。
7. 不要删除题库记录，不要删除题目。
8. 使用普通账号重新进入首页和“查看更多”验收。

恢复模块时，把对应题库的 `status` 改回字符串 `enabled`。

注意：只修改 `subjects.status` 不能保证模块从当前版本中隐藏。必须修改 `question_banks` 中对应题库的 `status`。

### 3.5 模块改名

模块改名会涉及 `subjects`、`question_banks` 和题目归属，不建议由普通运营人员直接操作。正确做法是联系技术管理员统一迁移。不要只改一条题库记录，否则可能出现同一模块被拆成两个分类。

## 4. 打卡海报图片和励志文字

### 4.1 更换打卡海报背景

打卡页面是竖向展示，但最终朋友圈分享图是 1080 x 1080 的正方形。

推荐优先提供：

- 正方形：1080 x 1080 像素
- JPG 或 PNG
- sRGB
- 建议不超过 5MB

最终分享图底部约 286 像素会叠加深色文字区。背景图的重要人物、Logo 和标题尽量放在上方约 70% 区域，不要放在最底部。

竖图也可以使用。系统会在正方形分享图中保留完整竖图，并用柔化背景填充两侧。

操作流程：

1. 进入“我的 -> 打卡背景管理”。
2. 填写背景标题。
3. 填写生效日期：
   - 填 `default`：加入每日轮播。
   - 填具体日期，例如 `2026-08-01`：只在这一天优先使用。
4. 点击“选择并上传背景图”。
5. 检查预览。
6. 点击“保存背景配置”。
7. 在下方列表确认状态为“启用中”。

如果同一具体日期有多张启用中的图片，系统只会取排序最靠前的一张。建议同一天只保留一张启用。多张 `default` 背景会按日期轮换。

重要说明：用户在“屏保壁纸”中点击过“用于打卡”后，该用户的自定义壁纸会优先于管理员打卡背景。因此，管理员更换背景后，少数用户仍可能看到自己的壁纸，这是当前设计，不是后台未生效。

验收时请使用没有设置过自定义打卡壁纸的普通测试账号，或先清理该测试账号的小程序本地缓存。

### 4.2 更换打卡励志文字

1. 进入“我的 -> 打卡文案管理”。
2. 填写打卡文案。
3. 填写生效日期：
   - `default`：参与每日轮播。
   - `YYYY-MM-DD`：只在指定日期优先使用。
4. 点击“保存文案配置”。
5. 在下方列表确认状态为“启用中”。

朋友圈分享图最多显示 2 行励志文字，过长内容会显示省略号。建议：

- 控制在 30 个汉字以内。
- 使用完整短句。
- 不使用复杂表情和生僻符号。
- 不在文案中手工输入大量空格或换行。

示例：

```text
今日完成一点点，未来上岸一大步。
```

### 4.3 停用和恢复

背景和文案列表右侧都有“停用/启用”按钮：

- 点击“停用”：普通用户不再使用该内容。
- 点击“启用”：重新加入指定日期或默认轮播。

停用后用普通账号重新打开打卡页面进行验收。

## 5. 激活广告和设置广告

广告需要完成两步：

1. 在微信公众平台开通流量主并创建广告位。
2. 把广告位 `unitId` 填入仕舟小程序管理员页面。

只完成其中一步，广告都不会正常展示。

### 5.1 在微信公众平台开通流量主

1. 电脑打开 [微信公众平台](https://mp.weixin.qq.com/)。
2. 使用该小程序管理员微信扫码登录。
3. 确认当前账号是“仕舟”小程序，不是公众号或其他小程序。
4. 在左侧菜单找到“流量主”。不同后台版本可能显示在“推广”“广告与服务”或相近菜单下。
5. 如果平台显示可以开通，按提示完成主体、结算账户和协议确认。
6. 等待平台审核或能力生效。

开通资格、结算规则和可创建的广告类型以微信公众平台当前页面为准，代码无法绕过平台限制。

### 5.2 创建三个广告位

在流量主的“广告位管理”中分别创建：

| 仕舟配置位置 | 微信广告类型 | 用途 |
| --- | --- | --- |
| 学习计划页横幅 | Banner 广告 | 学习计划页按钮上方 |
| 题目页横幅 | Banner 广告 | 作答后答案/解析区域附近 |
| 舟币激励视频 | 激励视频广告 | 用户完整观看后奖励 1 舟币 |

三个位置必须使用与类型匹配的正式广告位 ID。不要把 Banner 广告 ID 填到激励视频位置，也不要把同一个 ID 随意复制到三个位置。

创建完成后，复制形如 `adunit-xxxxxxxxxxxxxxxx` 的广告位 ID。

微信广告组件参考：[微信小程序广告能力文档](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/ad/banner-ad.html)

### 5.3 在仕舟小程序中设置

1. 打开“仕舟”小程序。
2. 进入“我的 -> 广告位管理”。
3. 选择广告位。
4. 显示名称可以使用默认名称。
5. 粘贴微信广告 `unitId`。
6. 备注中写明创建日期和用途。
7. 点击“保存广告位配置”。
8. 在下方列表确认状态为“启用中”。
9. 分别完成三个广告位。

如果不填写 `unitId`，保存后的广告位会处于停用状态。

### 5.4 广告验收

使用非 VIP 的普通用户真机测试：

- [ ] 学习计划页显示 Banner 广告
- [ ] 题目作答并显示答案后出现 Banner 广告
- [ ] 舟币明细页可以打开激励视频
- [ ] 中途关闭激励视频不会奖励舟币
- [ ] 完整看完后增加 1 舟币
- [ ] 舟币明细出现“观看完整广告奖励”

基础 VIP 和高级 VIP 用户不会显示学习计划页和题目页 Banner 广告，所以不能使用 VIP 账号验收这两个广告位。

广告可能因为微信库存、地区、频控、账号状态或平台审核暂时不展示。开发者工具中的效果也可能与真机不同，最终以正式版真机测试为准。

### 5.5 临时停用广告

进入“我的 -> 广告位管理”，在对应记录右侧点击“停用”。重新启用时点击“启用”。

## 6. 修改帮助与反馈内容

### 6.1 操作流程

1. 进入“我的 -> 帮助反馈配置”。
2. 修改“页面标题”。
3. 修改“页面说明”。
4. 检查“客服二维码路径”。
5. 修改“复制反馈说明”。
6. 按规定格式填写常见问题。
7. 点击“保存帮助配置”。

### 6.2 常见问题格式

每行一条，必须使用全角竖线 `｜` 分隔问题和答案：


错误示例：

```text
问题：课程点不开
答案：重新进入
```

上述错误格式无法被系统识别成一条 FAQ。

### 6.3 客服二维码

当前默认路径为：

```text
/QRcode.png
```

这是代码包内的客服二维码，不是小程序码。

如果要更换客服二维码：

- 最稳妥的方式是由技术人员替换项目根目录中的 `QRcode.png`，再上传并发布新版本。
- 也可以填写稳定的云图片地址，但不要填写会过期的临时链接。
- 当前帮助配置页只能填写路径，不能直接选择并上传二维码图片。

### 6.4 修改后验收

1. 使用普通账号进入“我的 -> 帮助与反馈”。
2. 检查标题、说明和每条 FAQ。
3. 点击“复制反馈说明”，检查剪贴板内容。
4. 点击“查看二维码”。
5. 长按二维码，确认能够识别并添加正确客服。

## 7. 向用户群发信息

### 7.1 当前功能边界

“消息推荐管理”发送的是仕舟小程序内的站内消息。用户打开小程序并进入底部“消息”页后可以看到。

它不是微信聊天消息，也不是微信公众号群发，更不会在用户未打开小程序时强制推送到微信。

### 7.2 发送流程

1. 进入“我的 -> 消息推荐管理”。
2. 填写消息标题。
3. 填写消息内容。
4. 填写推送范围。
5. 填写图标，例如 `📢`。
6. 点击“保存消息”。
7. 在下方列表确认状态为“启用中”。

### 7.3 推送范围

范围必须严格填写下列值之一：

| 范围值 | 接收用户 |
| --- | --- |
| `all` | 所有已登录用户 |
| `vip` | 当前有效 VIP 用户 |
| `new` | 新用户/试用用户 |
| `supervision` | 当前有效督学用户 |

不要填写“所有人”“全部”“VIP用户”等自定义文字。系统不认识的范围值会导致消息不展示。

### 7.4 消息示例

```text
标题：8月题库更新通知
内容：常识、资料分析模块已更新本月专项题，请前往考点记忆卡查看。
范围：all
图标：📢
```

### 7.5 停止展示

在消息列表右侧点击“停用”。停用后新进入消息页的用户不再看到该条全局消息。

当前功能不支持在管理员页面选择某一个具体用户单独发消息。

### 7.6 验收

1. 使用符合范围条件的普通账号打开小程序。
2. 进入底部“消息”页。
3. 检查标题、正文和图标。
4. 再使用一个不符合范围条件的账号，确认该账号看不到消息。

## 9. 给特定用户免费开通权限

### 9.1 操作权限和风险

当前小程序管理员页面没有“搜索用户并赠送会员”的按钮。免费开通需要在正式环境云数据库中修改用户记录。

此操作仅允许微信开发者工具和云开发环境的高级管理员执行。普通内容运营人员不要操作。

手工赠送不会产生支付订单，用户的“我的订单”中不会出现该次赠送。管理员必须单独保留赠送记录。

### 9.2 先让用户完成登录

1. 让目标用户打开正式版“仕舟”小程序。
2. 让用户完成手机号授权登录。
3. 记录用户提供的手机号和昵称。
4. 确认用户已经至少成功登录一次。

数据库中的手机号字段名是 `phone`。

### 9.3 查找目标用户

1. 打开微信开发者工具中的仕舟项目。
2. 点击“云开发”。
3. 确认当前环境为 `cloud-2ge02vrucaf8a6ab`。
4. 进入“数据库 -> users”。
5. 按 `phone` 精确查找用户。
6. 同时核对 `nickName`。
7. 必须确认只找到 1 条记录。

如果找不到用户：

- 让用户重新完成手机号登录。
- 确认手机号没有空格。
- 不要仅凭相似昵称修改记录。

如果找到多条记录，立即停止并联系技术管理员确认 `_openid`。

### 9.4 修改前备份

修改前记录以下字段：

- `_id`
- `_openid`
- `phone`
- `nickName`
- `isVip`
- `vipExpireDate`
- `supervisionExpireDate`
- `isFreeTrial`
- `lastVipPlanCode`
- `lastVipPlanLabel`

建议截图并登记赠送原因、审批人、开始时间和结束时间。

### 9.5 权限字段对照

日期字段应使用数据库的 Date 类型，并设置为未来时间。不要填写中文日期，不要使用已过期日期。

| 赠送类型 | 需要设置的字段 |
| --- | --- |
| 基础 VIP 包年 | `isVip=true`；`vipExpireDate=未来365天`；`isFreeTrial=false` |
| 督学试用 1 日 | `isVip=true`；`vipExpireDate=未来365天`；`supervisionExpireDate=未来1天`；`isFreeTrial=false` |
| 督学包月 | `isVip=true`；`vipExpireDate=未来365天`；`supervisionExpireDate=未来30天`；`isFreeTrial=false` |
| 高级 VIP/督学包年 | `isVip=true`；`vipExpireDate=未来365天`；`supervisionExpireDate=未来365天`；`isFreeTrial=false` |

如果用户当前权益尚未过期，应在原到期日基础上延长，不要直接用“今天 + 天数”覆盖，否则可能缩短用户已有权益。

可以同时填写便于客服识别的字段：

| 赠送类型 | `lastVipPlanCode` | `lastVipPlanLabel` |
| --- | --- | --- |
| 基础 VIP 包年 | `basic_vip_year` | `人工赠送基础VIP` |
| 督学试用 1 日 | `supervision_trial_day` | `人工赠送督学试用` |
| 督学包月 | `supervision_month` | `人工赠送督学包月` |
| 高级 VIP/督学包年 | `premium_vip_year` | `人工赠送高级VIP` |

### 9.6 禁止修改的字段

除非技术负责人明确批准，不要修改：

- `_id`
- `_openid`
- `appid`
- `role`
- `isAdmin`
- `coins`
- `createdAt`
- 支付订单和交易流水

### 9.7 用户侧生效和验收

1. 保存数据库修改。
2. 让用户彻底关闭仕舟小程序。
3. 从微信最近使用列表中重新打开。
4. 进入“我的”，等待用户信息刷新。
5. 检查 VIP 标识。
6. 测试 VIP 题库。
7. 赠送督学时，进入督学页面检查有效期和服务入口。
8. 使用非 VIP 账号对照，确认权限没有错误发给其他用户。

如果仍未生效：

1. 再次核对修改的是正式环境。
2. 核对 `vipExpireDate` 和 `supervisionExpireDate` 是否为未来日期。
3. 核对字段类型是否为 Date。
4. 核对目标记录的手机号和 `_openid`。
5. 不要重复创建用户记录。

## 11. 常见问题

### 11.1 上传后普通用户看不到

依次检查：

1. 是否上传到正式版小程序使用的云环境。
2. 内容是否处于启用状态。
3. 是否选错模块或资料类型。
4. 是否使用普通账号重新进入页面。
5. 是否需要下拉刷新或彻底关闭后重开。

### 11.2 音频上传成功但分类为空

检查上传时选择的模块。磨耳朵使用固定简称：常识、数量、言语、逻辑、资料、申论、综应、面试。

### 11.3 新打卡背景没有显示

检查：

1. 生效日期是否为今天或 `default`。
2. 配置是否启用。
3. 同一天是否有多张启用背景。
4. 测试用户是否设置过自己的“用于打卡”壁纸。

### 11.4 广告不显示

检查：

1. 微信公众平台流量主是否已开通。
2. 广告位是否已通过平台审核。
3. 广告类型和位置是否匹配。
4. `unitId` 是否完整。
5. 小程序中的广告配置是否启用。
6. 是否使用了 VIP 账号测试 Banner。
7. 是否使用正式版真机测试。

### 11.5 群发消息没有微信通知

当前功能是小程序内站内消息，不是微信聊天群发或系统通知。用户需要打开小程序并进入“消息”页查看。

### 11.6 免费开通后订单中心没有记录

这是人工赠送，不经过支付系统，因此不会生成订单。请使用本手册中的“人工赠送登记模板”留档。

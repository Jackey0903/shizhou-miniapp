# 仕舟小程序管理员运营操作手册

适用对象：仕舟小程序客户管理员、内容运营人员

操作设备：安装最新版微信的手机
操作原则：日常运营全部在小程序“管理员工作台”完成，不需要修改代码或数据库

---

## 1. 登录管理员工作台

### 1.1 进入路径

1. 使用已开通管理员权限的微信账号打开“仕舟公考”小程序。
2. 完成小程序登录。
3. 点击底部“我的”。
4. 点击“管理员工作台”。

进入后可以看到三个区域：

| 区域 | 可操作内容 |
| --- | --- |
| 题库与学习内容 | 题目录入、模块与题库、磨耳朵音频、领取资料、平台壁纸 |
| 运营配置 | 打卡海报、励志文字、广告位、帮助与反馈、站内群发、学习提醒 |
| 用户与交付 | 用户权限赠送、正式小程序码、VIP 套餐 |

### 1.2 看不到“管理员工作台”

先确认：

1. 当前微信是不是客户指定的管理员微信。
2. 小程序是否已经登录。
3. 是否误用了体验版、旧版本或其他微信账号。

仍看不到时，联系软件服务商核对管理员授权。管理员身份不能由普通用户自行开通。

### 1.3 通用操作规则

1. 上传或修改后，先用管理员账号预览。
2. 需要暂时隐藏内容时点击“下线”，不要删除原文件。
3. 模块和题库下线不会删除题目、答题记录或学习记录。
4. 发布群发消息、赠送用户权限前必须再次核对对象。
5. 大批量上传时保持微信在前台，等待成功提示后再退出。

## 3. 批量上传题库

### 3.1 先准备模块和题库

如果要导入新的模块或题库：

1. 进入“管理员工作台 -> 模块与题库”。
2. 点击“新增模块”，填写模块名称和排序。
3. 保存模块。
4. 点击“新增题库”，选择所属模块。
5. 填写题库名称、标签和说明。
6. 如仅限 VIP 使用，勾选“仅VIP可用”。
7. 保存题库。

CSV 中的“科目名称”和“题库名称”必须与这里完全一致。

### 3.2 使用固定 CSV 模板

1. 进入“管理员工作台 -> 题目录入”。
2. 点击“发送 CSV 模板”。
3. 将模板发到文件传输助手或负责整理题库的人员。
4. 用 Excel 或 WPS 填写。
5. 另存为“CSV UTF-8（逗号分隔）”。

固定表头不能删除、改名或换序：

```text
科目名称,题库名称,序号,题型,题目,选项A,选项B,选项C,选项D,答案,解析,图片URL
```

### 3.3 字段规则

| 字段 | 规则 |
| --- | --- |
| 科目名称 | 必填，必须与模块名称一致 |
| 题库名称 | 必填，必须与题库名称一致 |
| 序号 | 可选，建议使用正整数 |
| 题型 | 只能填“选择题”或“填空题” |
| 题目 | 必填，每题一行 |
| 选项A-D | 选择题至少连续填写 A、B |
| 答案 | 选择题只填 A/B/C/D；填空题填完整答案 |
| 解析 | 建议填写 |
| 图片URL | 可选，只支持 `https://` 或 `cloud://` |

题目图片建议宽度不低于 1080 像素，文字清晰。不要使用需要登录、会过期或带防盗链的临时地址。

### 3.4 导入

1. 将 CSV 发到管理员微信的文件传输助手。
2. 打开“题目录入”。
3. 点击“选择 CSV 文件”。
4. 查看校验结果、错误行号和题目预览。
5. 有错误时修改原 CSV 后重新选择。
6. 校验通过后点击“确认导入”。
7. 等待导入完成提示。

系统会自动分批上传并跳过重复题。单个 CSV 最大 5MB、最多 5000 题。

### 3.5 导入后检查

- [ ] 模块和题库名称正确
- [ ] 题目数量正确
- [ ] 至少打开 2 道选择题
- [ ] 至少打开 2 道填空题
- [ ] 答案和解析正确
- [ ] 题目图片正常显示
- [ ] VIP 题库对普通用户正确拦截

## 4. 模块与题库管理

### 4.1 新增模块

1. 进入“管理员工作台 -> 模块与题库”。
2. 点击“新增模块”。
3. 填写模块名称，例如：常识、言语理解、逻辑判断、数量关系、资料分析、申论、综应、面试。
4. 填写排序数字。数字越小越靠前。
5. 保持“保存后立即上线”勾选。
6. 点击“保存模块”。

### 4.2 编辑模块

1. 找到模块。
2. 点击“编辑”。
3. 修改名称、说明、主题色或排序。
4. 点击“保存模块”。

模块改名后，系统会同步更新该模块下的题库分类。

### 4.3 下线和恢复模块

1. 找到目标模块。
2. 点击“下线”并确认。
3. 用户端将不再显示该模块。
4. 需要恢复时点击“上线”。

下线不会删除题目和用户记录。

### 4.4 新增或编辑题库

1. 点击“新增题库”，或在目标模块下点击“在此模块新增题库”。
2. 选择所属模块。
3. 填写题库名称、标签、说明和排序。
4. 需要 VIP 权限时勾选“仅VIP可用”。
5. 点击“保存题库”。

已存在的题库可以点击“编辑”修改。题库也可以单独上线或下线。

## 5. 批量上传磨耳朵音频

### 5.1 文件准备

支持：

- `.mp3`
- `.wav`
- `.m4a`

建议使用 MP3，码率 64-128kbps，单个文件不超过 20MB。上传前先把文件名改成用户能看懂的标题。

### 5.2 上传

1. 将音频发到管理员微信的文件传输助手。
2. 进入“管理员工作台 -> 磨耳朵音频”。
3. 选择所属模块。这里会自动读取“模块与题库”中已上线的模块。
4. 选择标签：晨听、单词、技巧或素材。
5. 时长说明可填 `05:20`，也可以留空。
6. 点击“选择音频文件”，单次最多 9 个。
7. 点击“开始批量上传”。
8. 等待进度完成。

### 5.3 管理

页面下方“最近音频”会显示上传结果：

- 点击“下线”可从用户端隐藏。
- 点击“上线”可恢复。

上传后进入普通用户的“磨耳朵”页面播放抽查。

## 6. 批量上传领取资料

每份资料首次领取固定消耗 10 舟币，领取后重复打开不再扣费。

### 6.1 支持格式

文档：

- PDF、Word、Excel、PowerPoint、TXT

音频：

- MP3、WAV、M4A

图片：

- JPG、JPEG、PNG

### 6.2 批量上传文件

1. 进入“管理员工作台 -> 领取资料”。
2. 选择“文档”“音频”或“图片”。
3. 点击选择文件，单次最多 9 份。
4. 在文件列表中逐条检查并修改资料标题。
5. 填写本批资料的统一说明。
6. 点击“开始上传”。
7. 等待全部文件上传完成。

文档和音频从微信聊天文件中选择；图片从手机相册选择。

### 6.3 给文档和音频匹配封面

1. 先选择资料文件。
2. 点击“按文件顺序选择封面”。
3. 按资料列表顺序选择同样数量的封面图。
4. 第 1 张封面匹配第 1 份资料，第 2 张匹配第 2 份，以此类推。
5. 文件列表出现“已匹配第X张封面”后再上传。

如果不选封面，用户端会显示文档或音频默认图标。

### 6.4 发布外部链接

没有本地文件时，可以：

1. 选择资料类型。
2. 不选择文件。
3. 填写资料标题。
4. 填写 `https://` 开头的链接。
5. 点击上传。

不要填写 HTTP、临时网盘地址或需要登录才能访问的链接。

### 6.5 图片和封面尺寸

| 用途 | 推荐尺寸 | 比例 | 格式 |
| --- | ---: | ---: | --- |
| 资料图片正文 | 1080×1080 或更高 | 1:1 或按内容比例 | JPG/PNG |
| 资料列表封面 | 800×800 | 1:1 | JPG/PNG |
| 题目配图 | 宽度至少 1080 | 按内容比例 | JPG/PNG |

图片文字要清晰，四周保留安全边距。单张建议不超过 5MB。

### 6.6 上线和下线

页面下方“最近资料”显示当前状态：

- “已上线”表示用户可领取。
- 点击“下线”后用户不再看到。
- 点击“上线”可恢复。

下线不会影响已经领取该资料的用户记录。

## 7. 批量上传壁纸

### 7.1 图片标准

| 项目 | 建议 |
| --- | --- |
| 尺寸 | 1080×1920 |
| 比例 | 9:16 竖版 |
| 格式 | JPG 或 PNG |
| 大小 | 单张不超过 5MB |
| 安全区 | 重要人物和文字不要贴近上下边缘 |

### 7.2 上传和管理

1. 进入“管理员工作台 -> 平台壁纸”。
2. 点击“从相册选择壁纸”。
3. 单次最多选择 9 张。
4. 逐张修改壁纸标题。
5. 点击“开始上传”。
6. 在下方列表确认已上线。

不需要展示时点击“下线”，需要恢复时点击“上线”。

## 8. 打卡海报和励志文字

打卡分享最终生成 1080×1080 正方形图片。

### 8.1 更换海报背景

1. 进入“管理员工作台 -> 打卡海报”。
2. 填写背景标题。
3. 生效日期填写：
   - `default`：加入默认每日轮播。
   - `2026-08-01`：仅指定日期生效。
4. 点击“选择并上传背景图”。
5. 预览图片。
6. 点击“保存背景配置”。

背景图建议使用 1080×1080 正方形。竖图也可以使用，但生成海报时会完整缩放并补背景。

### 8.2 更换励志文字

1. 进入“管理员工作台 -> 励志文字”。
2. 输入海报文案。
3. 生效日期填 `default` 或具体日期。
4. 点击“保存文案配置”。

建议 15-35 个汉字，最多两行。避免过长导致字号变小或省略。

### 8.3 上线和下线

背景图和文案都可以单独停用或恢复。指定日期内容优先于默认轮播内容。

### 8.4 真机验收

1. 使用普通用户完成当日学习和打卡。
2. 打开打卡记录。
3. 点击分享按钮。
4. 检查背景、文案、日期、打卡次数是否正确。
5. 完成分享或保存后检查舟币变化。

## 9. 广告设置

### 9.1 微信平台的一次性准备

首次使用广告前，小程序主体管理员必须在微信公众平台完成：

1. 开通流量主资格。
2. 创建横幅广告位或激励视频广告位。
3. 复制微信生成的 `adunit-` 开头的 unitId。

这是微信平台对主体资质和结算的强制管理，不能由小程序代码代替。完成一次性开通后，日常广告配置和启停都在管理员工作台操作。

### 9.2 配置广告位

1. 进入“管理员工作台 -> 广告位”。
2. 选择位置：
   - 学习计划页横幅
   - 题目页横幅
   - 舟币激励视频
3. 粘贴 `adunit-` 开头的正式 unitId。
4. 点击“保存广告位配置”。

同一位置再次保存会更新原配置，不会生成重复广告位。

### 9.3 启停

- 点击“停用”：小程序不再请求该广告。
- 点击“启用”：恢复广告请求。

广告是否实际展示还受微信库存、地区、频控和账号状态影响。最终以正式版真机为准。

## 10. 修改帮助与反馈

1. 进入“管理员工作台 -> 帮助与反馈”。
2. 修改页面标题和页面说明。
3. 点击“从相册选择客服二维码”上传最新客服二维码。
4. 修改反馈说明。
5. 编辑常见问题。
6. 点击“保存帮助配置”。

常见问题每行一条，格式必须是：

```text
问题｜答案
```

示例：

```text
资料打不开怎么办？｜请检查网络后重新打开，仍失败时将页面截图发给客服。
如何开通督学？｜进入督学页面选择套餐并完成微信支付。
```

分隔符使用中文竖线 `｜`。

## 11. 向用户群发站内消息

### 11.1 发布

1. 进入“管理员工作台 -> 站内群发”。
2. 填写消息标题和内容。
3. 选择接收范围：
   - 全部用户
   - VIP 用户
   - 督学用户
   - 新用户
4. 设置消息图标。
5. 点击“立即发布”。

发布后，符合范围的用户会在小程序底部“消息”中看到。

### 11.2 撤回和恢复

- 点击“撤回”：用户端不再展示该消息。
- 点击“恢复”：消息重新展示。

站内群发是小程序内部消息，不会绕过微信授权向用户手机发送系统通知。微信外部通知需要用户主动订阅。

## 12. 获取和保存正式小程序码

1. 进入“管理员工作台 -> 正式小程序码”。
2. 首次进入时点击“生成正式码”。
3. 看到“已连接线上正式版本”后，点击二维码可预览。
4. 点击“保存到相册”。
5. 将图片发送给客户、门店或宣传人员。

重新发布版本后，小程序码通常不需要更换；它会始终打开正式线上小程序。需要刷新文件时点击“重新生成”。

如果提示生成失败，先确认小程序已经有线上版本，再联系软件服务商检查云函数部署。

## 13. 给特定用户免费开通权限

### 13.1 查找用户

1. 用户必须至少登录过一次小程序。
2. 进入“管理员工作台 -> 用户权限赠送”。
3. 输入用户完整手机号或昵称。
4. 点击“搜索”。
5. 核对昵称、手机号、VIP 到期日和督学到期日。
6. 点击目标用户右侧“选择”。

手机号搜索要求用户登录时已经授权绑定手机号。无法按手机号找到时，可以使用昵称搜索。

### 13.2 选择赠送套餐

| 套餐 | 新增权益 |
| --- | --- |
| 基础VIP包年 | VIP 365 天 |
| 督学试用 | VIP 365 天 + 督学 1 天 |
| 督学包月 | VIP 365 天 + 督学 30 天 |
| 高级VIP/督学包年 | VIP 365 天 + 督学 365 天 |

有效期会在用户现有有效期后继续累计，不会覆盖剩余天数。

### 13.3 确认开通

1. 选择套餐。
2. 填写赠送原因或审批备注。
3. 点击“确认开通”。
4. 在确认弹窗再次核对用户和套餐。
5. 点击确认。

页面下方会保存最近赠送记录，包括用户、套餐、原因和操作时间。

人工赠送不产生支付订单，所以用户的“我的订单”中不会出现该次赠送。用户重新进入“我的”或督学页面即可看到新有效期。

## 14. VIP 套餐管理

四个正式套餐的金额、有效期和微信道具 ID 已由系统锁定，客户管理员不能改坏支付配置。

管理员可以：

1. 选择固定套餐。
2. 修改用户端展示的权益说明。
3. 保存套餐展示。
4. 上线或下线套餐。

下线套餐后用户不能购买，但历史订单和已发放权益不受影响。

正式套餐：

| 套餐 | 价格 | 微信道具 |
| --- | ---: | --- |
| 基础VIP包年 | ¥198 | `sz_basic_vip_year` |
| 督学试用1日 | ¥8 | `sz_supervision_1d` |
| 督学包月 | ¥198 | `sz_supervision_mon` |
| 高级VIP/督学包年 | ¥988 | `sz_premium_vip_year` |

## 15. 日常发布检查清单

### 15.1 内容上传后

- [ ] 标题和分类正确
- [ ] 文件可以打开、播放或预览
- [ ] 图片清晰且没有裁掉重要文字
- [ ] 资料领取显示 10 舟币
- [ ] 不需要的旧内容已下线

### 15.2 题库更新后

- [ ] 模块顺序正确
- [ ] 题库名称正确
- [ ] 选择题、填空题各抽查至少 2 道
- [ ] 答案和解析正确

## 16. 常见问题

### 16.1 上传按钮没有反应

确认当前账号是管理员、网络正常，并重新进入管理员工作台。批量上传期间不要连续点击按钮。

### 16.2 CSV 校验不通过

按照页面显示的错误行号修改。重点检查表头、题型、选择题答案、连续选项和图片 URL。

### 16.3 上传成功但用户端看不到

检查该内容是否已上线，退出对应用户页面后重新进入。模块下线时，其下所有题库都会隐藏。

### 16.4 资料图片没有封面

图片资料会自动使用自身作为封面。文档和音频需要先选择文件，再按顺序选择封面。

### 16.5 广告不展示

检查 unitId、广告位类型和启用状态。即使配置正确，微信也可能因库存、频控或地区暂不展示。

### 16.6 搜不到用户

用户必须登录过小程序。手机号搜索还要求用户已授权绑定手机号，可以改用昵称搜索。

### 16.7 赠送后订单中心没有记录

管理员赠送不经过支付，不生成订单。请在“最近赠送记录”中核对。

### 16.8 正式小程序码生成失败

确认小程序已有线上版本。仍失败时联系软件服务商检查 `adminOperations` 云函数。

## 17. 客户交付验收

交付前由客户管理员独立完成以下操作：

1. 登录并进入管理员工作台。
2. 新增一个测试模块和测试题库，再下线。
3. 导入小批量 CSV 并完成一道题。
4. 批量上传两个音频、两份资料和两张壁纸。
5. 更换一张打卡背景和一条励志文字。
6. 保存一个广告位配置并测试停用、启用。
7. 修改一条帮助 FAQ 和客服二维码。
8. 给测试用户发布一条站内消息。
9. 生成并保存正式小程序码。
10. 给测试用户赠送督学试用，并核对到期日。

以上操作均正常后，客户即可独立完成日常运营。

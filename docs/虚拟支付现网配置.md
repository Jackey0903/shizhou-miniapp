## 微信平台约束

1. 道具 ID 只能包含字母、数字、下划线和连字符，长度不超过 20 个字符。
2. 道具价格单位为分，必须与 `vip_plans.price` 完全一致。
3. 商品图必须是公开可访问的 `200×200` JPG/PNG。
4. 道具必须先上传成功，再发布到正式环境；发布成功状态为 `publish_status=2`。
5. 新发布道具可能需要数分钟生效。客户端 `-15010` 表示未发布，`-15013` 表示价格不一致，`-15014` 表示刚发布尚未生效。

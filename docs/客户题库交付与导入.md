# 客户题库交付与导入

## 客户提交标准

客户只提交一个 `.csv` 文件。文件必须使用管理员从小程序“我的 -> 题目录入 -> 发送 CSV 模板”发出的固定模板，不接收 `.xlsx`、`.xls`、Word 或 PDF 作为直接导入文件。

固定表头不得删除、改名或换序：

`科目名称,题库名称,序号,题型,题目,选项A,选项B,选项C,选项D,答案,解析,图片URL`

- 每题一行，科目名称、题库名称、题型、题目、答案必填。
- 题型只能写“选择题”或“填空题”。
- 选择题至少填写 A、B 两项，不能跳列，答案只写 A/B/C/D。
- 填空题不填选项，答案写完整参考答案。
- 图片可不填；需要图片时只填可访问的 `https://` 或 `cloud://` 地址。
- Excel/WPS 保存时必须选择“CSV UTF-8（逗号分隔）”。

## 管理员最快导入流程

1. 在小程序进入“我的 -> 题目录入”。
2. 点“选择 CSV 文件”，从微信聊天选择客户发来的文件。
3. 查看校验结果和前 5 题预览；有错误时按明确行号让客户修改。
4. 校验通过后点“确认导入”。系统自动按科目和题库名称创建分类，重复题自动跳过。
5. 导入完成后进入对应题库，分别打开一题选择题和一题填空题，核对题干、答案、解析和图片。

单个文件最大 5 MB、最多 5000 题。大批量题库建议按科目拆成多个 CSV，便于复核和重试。
